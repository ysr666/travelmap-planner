# Limited Beta 用户指南

更新时间：2026-07-28

旅图 TripMap 的 Limited Beta 正在从账号同步 PWA 升级为 **实时在线、AI 优先的旅行操作系统**。你可以先看当前行程，也可以直接告诉全局 AI 想完成什么。当前版本已经支持一批可执行 AI 动作；完整 Realtime 云端状态、天气、航班、铁路、实时交通和票务状态仍在后续版本接入。

## 使用前

- 需要登录 Supabase 账号后才能进入业务页面。
- 默认在线使用，账号数据会自动同步；后续版本会升级为云端写入优先和 Realtime 更新。
- 已联网验证的设备会获得 30 天离线访问期；联网后会自动续期。
- 当前旅行仍按账号隔离缓存在本机 IndexedDB；它将逐步降为弱网缓存和失败 outbox。
- 如果发现旧本机全局数据，应用会让你选择“接管本机数据”或“仅恢复云端”。

## AI

- 直接说出目标即可；AI 会识别当前旅行、选择登记动作并尽量完成任务，而不是只返回说明文字。
- 只读查询和导航可直接完成；一组可逆写入只显示一次最终确认；付款、取消订单、发送消息和权限修改仍需单独确认。
- AI Draft 和 AI Trip Edit 可能生成错误地点、时间、顺序或备注，导入和应用前都要人工核对。
- 当前可以打开票据、补全地点、调整时间、重排、移动、可逆删除、更新进度、生成路线预览、创建费用草稿和一键修复。
- AI 只会调用已登记动作，不能选择任意函数、路由、数据库 ID 或 Provider 密钥。

## 搜索与地点

- 实时结果会逐步统一显示来源、查询时间和有效期；过期信息不继续显示为当前事实。
- 当前 Place / Search 覆盖仍有限，营业时间、价格、临时关闭和活动信息可能不可用。
- 地点查找当前返回候选并在确认后写入；路线图将支持 AI 批量补全和自动刷新过期事实。

## 路线和地图

- 当前路线是预览，不包含语音导航、turn-by-turn 指令或完整实时交通；路线图将接入带出发时间和 TTL 的实时 ETA。
- 公交、火车、飞机等复杂交通不会自动生成真实换乘方案。
- 地图底图依赖网络，PWA 不缓存商业地图瓦片。
- 生成路线会把相邻地点坐标发送给 TripMap provider proxy 及其后端 provider。

## 云同步

- 当前本机写入后会进入同步队列；不同对象可自动合并，同一字段冲突会要求确认。
- 目标架构会让在线写入直接获得云端 ack，并通过 Realtime 推送到其他设备和同行。
- copy 票据文件会作为账号票据 Blob 单独同步。

## 同行共享

- 主人可以给同行维护证件、座位、房间、保险和紧急联系人等资料摘要。
- 票据可共享给所有同行，也可只指定给部分同行；指定名单为空时表示不共享给任何同行。
- 被授权同行可打开主人已同步的 copy 票据原件；授权、撤销和打开请求会进入主人端审计。
- 同行普通修改会自动进入主人端处理流，撤销重排等需要判断的请求仍保留确认。

## 出发前

- 确认账号数据已经同步；需要独立归档时仍可导出 zip。
- PWA 更新后可能需要刷新、关闭重开或重新添加到主屏幕。
- iOS Safari 和 Android Chrome 可能因系统存储策略清理 IndexedDB，本机缓存不是长期备份。

## 反馈时请说明

- 设备和浏览器。
- 旅行页面或路径。
- 是否在线、是否登录。
- 操作前后看到的提示。
- 不要在反馈中发送验证码、token 或完整证件/票据原件。
